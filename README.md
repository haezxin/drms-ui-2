# Disaster Response Management System

A responsive disaster-response operations interface for preparing and monitoring simulated drone missions. The prototype includes fire, flood, and emergency beacon modules, mission status, telemetry, and a tactical map.

## Run Locally

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

Authentication and mission data are prototype-only. Accounts are stored in the browser; there is no authentication backend.
